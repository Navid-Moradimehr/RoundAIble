⭕ RoundAIble

Multiple AI agents solve your coding task. They critique each other. The best code wins.

🧩 1. DesignDrag Input, Reasoning Agent, Critic and RoundAIble nodes onto a visual canvas.
⚔️ 2. CompeteAgents generate solutions in parallel and refine them through peer-review rounds.
🏆 3. WinCritics score every submission on a 0–10 scale; results stream in live.

🔌 Works with your models

OpenAI GPT‑5.6 · Anthropic Claude Opus 5 & Fable 5 · Google Gemini 3.7 · xAI Grok 4.20 · DeepSeek V4 · Kimi K3 · Qwen 3.8 · GLM‑5.3 · MiniMax M3 · Mistral · Groq · Perplexity · OpenRouter · plus local models via Ollama or any OpenAI-compatible endpoint (LM Studio, vLLM…).

🔒 Local-first: your code and API keys never leave your machine.

🚀 Run it locally — one command

npx github:Navid-Moradimehr/RoundAIble

First run installs & builds automatically, then opens localhost:4199. Windows users can also double-click scripts\start-windows.cmd; macOS: scripts/start-mac.command.
